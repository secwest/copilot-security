# Multi-hop vulnerable assign-deep merge

An Express JSON object crosses three relative-import wrappers into a source operand of `assignDeep(target, ...sources)`. The nearest runtime manifest pins `assign-deep` 0.4.7: the first repair excluded `__proto__`, but its recursive destination lookup still follows parser-produced `constructor.prototype` into `Object.prototype`. On a strict modern runtime, the global mutation occurs before a subsequent assignment to the read-only built-in prototype property throws; the route's application error boundary demonstrates that the exception does not roll the mutation back and a fresh authorization object observes the inherited state. This case deliberately exercises the later reviewed advisory range that extends beyond CodeQL's older boundary.
