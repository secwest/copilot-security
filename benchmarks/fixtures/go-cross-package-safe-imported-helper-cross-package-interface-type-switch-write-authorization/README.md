# Go imported helper cross-package interface authorization control

The imported parent helper creates a value layer containing a pointer holder,
copies the value three times, and converts its repository to an interface
declared in a separate package. Canonical type identities prove assignability
despite named-versus-unnamed parameters and different import aliases. Every
type-switch arm writes the selected primary repository through a different
copy. The primary deletion is bound to the authenticated account, so the
deterministic witness proves victim survival and successful owned deletion.
The archive implementation remains an exact dispatch decoy.
