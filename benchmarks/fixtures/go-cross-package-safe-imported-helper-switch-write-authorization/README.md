# Go imported helper switch authorization control

The imported parent helper creates a value layer containing a pointer holder,
copies the value three times, and writes the selected primary repository through
a different copy in each arm of an explicit `switch` with a final `default`.
Every path establishes the same shared holder before the original value is
returned. The primary deletion is bound to the authenticated account, so the
deterministic witness proves victim survival and successful owned deletion. The
archive implementation remains an exact dispatch decoy.
