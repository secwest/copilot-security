# MCP v2 fixed-destination control

This topology-matched control keeps the official SDK, schema-bearing tool, callback, same-file helper, `fetch`, timeout, response read, and tool response. The operator selects a loopback origin before module startup; tool input is confined to the POST body and cannot select the destination. The witness uses a disposable random-port loopback listener and closes it immediately.

Run `npm install` and `npm run witness` with Node.js 22 or later.
