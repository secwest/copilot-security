# Go imported helper aliased type-switch authorization control

The imported parent helper creates a value layer containing a pointer holder,
copies the value three times, carries its interface parameter through two exact
local aliases, then binds a type-switch guard from the final alias. The `nil`,
interface, and final default arms each write the selected primary repository
through a different copy, making initialization an all-path invariant. The
primary deletion is bound to the authenticated account, so the deterministic
witness proves victim survival and successful owned deletion. The archive
implementation remains an exact dispatch decoy.
