# Go imported helper initialized-switch authorization control

The imported parent helper creates a value layer containing a pointer holder,
copies the value three times, then binds a new scalar switch guard directly from
its string parameter. Each arm writes the selected primary repository through a
different copy, and the mandatory final `default` makes the initialization an
all-path invariant. The primary deletion is bound to the authenticated account,
so the deterministic witness proves victim survival and successful owned
deletion. The archive implementation remains an exact dispatch decoy.
