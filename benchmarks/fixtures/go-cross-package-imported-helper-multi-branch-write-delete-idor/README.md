# Go imported helper multi-way branch deletion

The imported parent helper creates a value layer containing a pointer holder,
copies the value three times, and writes the selected primary repository through
a different copy in each arm of an explicit `if / else if / else` chain. Every
path therefore establishes the same shared holder before the original value is
returned. The deterministic witness proves that the attacker-selected object
reaches the unscoped primary deletion. The archive store is an exact dispatch
decoy.
